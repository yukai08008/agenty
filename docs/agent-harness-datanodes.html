Agent Harness DataNodes

以业务事实和运行事实为边界，避免把流程、文件或 DTO 当成节点。

业务类节点运行类节点
业务事实 用户最终关心什么
运行事实 工作如何可靠推进
Identity → Goal
一个身份拥有多个用户目标
Task + Goal → Execution
定义与意图共同创建执行实例
Execution → Manifest
每次执行只绑定一个冻结上下文
Execution → RuntimeTurn
一次执行可顺序编排多个 Turn
Execution → Outcome
最多产生一个权威业务结果
Outcome → MemoryFact
结果只产生候选记忆，不静默覆盖
